# agentic-backend-go

A production-grade REST API boilerplate for **Go 1.27 · chi v5 · pgx v5 · sqlc · goose · Postgres 17**, with the [agentic-kit](https://github.com/kalpesh122/agentic-kit) built in: one `AGENTS.md` every AI coding agent reads, skills that encode how to add endpoints and migrations, hooks that block destructive commands and force `just check` to pass before an agent can say "done", and a multi-model (Claude + Codex + Gemini) code-review council in CI.

It is opinionated on purpose. Plain `net/http` handlers on chi, SQL you can read with a typed store generated by sqlc (drift is a CI failure), migrations embedded in the binary, one `Config` struct validated at boot, one error body everywhere, request ids in every log line, and tests at two levels: fast handler tests on an in-memory store and a real-Postgres integration test through Testcontainers. Tools are pinned with Go's `tool` directive, so `go tool sqlc`, `go tool goose`, and `go tool golangci-lint` need no global installs.

## 60-second quickstart

```bash
git clone https://github.com/kalpesh122/agentic-backend-go my-api && cd my-api
cp .env.example .env              # defaults work locally
just setup                        # go mod download (fetches the Go 1.27.1 toolchain if needed)
just docker-up                    # Postgres 17 on localhost:5435
just migrate                      # apply embedded goose migrations
just dev                          # http://localhost:8080/health (air live reload)
curl -H 'Authorization: Bearer dev-key' localhost:8080/api/notes
```

Requirements: Go ≥ 1.21 with `GOTOOLCHAIN=auto` (the justfile sets it), [just](https://github.com/casey/just), Docker (dev database and the integration test).

## What is inside

| Concern | Choice | Why |
|---------|--------|-----|
| Router | chi v5 on `http.Handler` | Zero magic, composable middleware, sub-routers; `middleware.RealIP` avoided (deprecated, spoofable) |
| DB | pgx v5 pool + sqlc-generated typed queries | The SQL is the source of truth; the store is generated, reviewed, and drift-checked |
| Migrations | goose SQL embedded via `embed.FS` | One binary carries its schema; `MIGRATE_ON_START` for containers, `bin/migrate` for pipelines |
| Config | `caarlos0/env` struct + validation | Every problem reported at once, `.env.example` mirrors the struct |
| Auth | Bearer API keys → principals (`API_KEYS=key:principal,…`) | Zero-dependency; principal scopes every query; swap in `internal/auth` |
| Errors | `apperr.Error` → `{"error": {"code", "message", "details?", "request_id"}}` | One shape for humans, clients, agents |
| JSON | `encoding/json/v2` (GA in Go 1.27) with `RejectUnknownMembers` | Faster, stricter request decoding |
| Logging | `log/slog` (JSON in production) with request ids | Standard library, structured |
| Tracing | OpenTelemetry OTLP/HTTP, opt-in via `OTEL_EXPORTER_OTLP_ENDPOINT` | Zero cost when unset |
| Rate limit | `go-chi/httprate` keyed by resolved client IP | In-memory default; swap the counter for Redis when horizontal |
| Lint | golangci-lint v2 (`standard` + errorlint, gosec, revive, unparam) | Config in v2 format; formatters section handles gofmt/goimports |
| Tests | testify + httptest + Testcontainers | Handler tests in <1 s; the SQL is proven on real Postgres |
| Image | `golang:1.27-alpine` → `distroless/static:nonroot` | ~15 MB, no shell, non-root |

## API at a glance

```
GET  /health  /ready
GET  /api/notes?limit=20&cursor=…   POST /api/notes   GET|PATCH|DELETE /api/notes/{id}
```

All `/api/notes` routes need `Authorization: Bearer <key>` and only return the caller's rows.

## How AI agents work in this repo

- `AGENTS.md` (≤150 lines) is the map: commands, layout, hard rules, definition of done. `CLAUDE.md` imports it; Gemini, Copilot, and Cursor point at it.
- Skills in `.claude/skills/` (mirrored in `.agents/skills/`): `add-endpoint`, `add-migration`, plus the kit's `brainstorm-spec`, `tdd`, `debug`, `code-review`, `council-review`, `verify-before-done`, `adr`, `git-hygiene`.
- Hooks in `.claude/settings.json`: block `rm -rf`, force pushes, `DROP TABLE`, reading `.env`; protect `go.sum`; gofmt every edited file; run `just check` when the agent tries to stop and block if it fails.
- Subagents: read-only `planner`, `reviewer`, `security-reviewer`, `explorer`; write-capable `tdd-implementer`; `council-synthesizer`.
- CI: `ci.yml` runs `just check` against a Postgres service and builds the image; `ai-council-review.yml` has three models review every PR and post one consolidated comment.
- `specs/001-notes/` shows the spec → plan → tasks flow; `docs/adr/` records why the stack looks like this.

## Swap-outs

- **Auth**: replace `auth.RequireAPIKey` with a JWT/OIDC verifier that calls `auth.WithPrincipal`; handlers keep using `auth.Principal(ctx)`.
- **Router**: handlers are `http.HandlerFunc`; moving to the stdlib `ServeMux` (Go 1.22+ patterns) means re-wiring `router.go` only.
- **Rate limiting**: pass `httprate.WithLimitCounter(...)` backed by Redis for multi-instance deployments.
- **Background jobs**: add `riverqueue/river` (Postgres-backed) and call it from the service layer; keep stores pure.
